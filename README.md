# Seda Digital Studio

The theme used is "hugo-serif-theme", which is included as a submodule from the repository at "https://github.com/zerostaticthemes/hugo-serif-theme.git".

To clone this repository and initiate the submodules, run:
```bash
git clone --recurse-submodules git@github.com:Alex-Seda/seda-digital-studio.git
```
